# zoomjomedia — Xray/V2Ray subscription generator

این پروژه فایل خام `fast/sub/normal` را از روی فیدهای Sing-box می‌سازد. خروجی یک اشتراک Base64 استاندارد شامل لینک‌های `vless://` است و نام‌ها به‌ترتیب `zoomjomedia 1`، `zoomjomedia 2` و ... می‌شوند.

## ساختار خروجی

پس از انتشار در یک مخزن عمومی با نام `amir` و حساب GitHub شما، آدرس خروجی این خواهد بود:

`https://raw.githubusercontent.com/Z5GIT/amir/main/fast/sub/normal`

## راه‌اندازی

1. در GitHub یک مخزن **Public** با نام `amir` بسازید و شاخهٔ اصلی آن `main` باشد.
2. محتویات این ZIP را استخراج کنید و **فایل‌ها و پوشه‌های داخل آن** را در ریشهٔ مخزن آپلود کنید؛ خود ZIP را به‌تنهایی آپلود نکنید.
3. در تب **Actions** اجرای `Build Xray subscription` را بررسی کنید. گردش‌کار با اولین commit به‌صورت خودکار اجرا می‌شود. در صورت نیاز، از گزینهٔ **Run workflow** هم می‌توان آن را دستی اجرا کرد.
4. پس از اجرای موفق، فایل `fast/sub/normal` با خروجی واقعی جایگزین می‌شود.

## اضافه‌کردن منبع

فایل `sources.json` را باز کنید و URL فید JSON بعدی را به آرایهٔ `sources` اضافه کنید. ترتیب نام‌گذاری میان همهٔ منابع پیوسته می‌ماند. هر منبع باید ساختاری سازگار با JSON کانفیگ Sing-box و دارای `outbounds` از نوع `vless` داشته باشد؛ همچنین فید متنی از قبل ساخته‌شده که خطوط `vless://` دارد، پشتیبانی می‌شود.

گردش‌کار هر ۳۰ دقیقه اجرا می‌شود و هنگام اجرای دستی نیز خروجی را تازه می‌کند. اگر هیچ منبعی در دسترس نباشد یا خروجی خالی شود، فایل قبلی حفظ می‌شود تا لینک اشتراک ناخواسته خالی نشود.

## نکتهٔ سازگاری

پارامترهای اتصال هر خروجی VLESS مانند سرور، پورت، UUID، Flow، TLS/Reality، SNI، fingerprint، کلید عمومی، short ID و transport تا حد فیلدهای قابل‌نمایش در URI حفظ می‌شوند. تنظیمات مختص کلاینت Sing-box مثل inboundهای محلی، DNS و قوانین route، بخشی از یک لیست لینک Xray/V2Ray نیستند و به‌عنوان تنظیمات کلاینت منتقل نمی‌شوند.

فید منبع: `sinavm/SVM` — منبع ممکن است تغییر کند یا بعضی سرورها از کار بیفتند؛ تولید لینک به معنی تضمین فعال‌بودن سرورها نیست.
